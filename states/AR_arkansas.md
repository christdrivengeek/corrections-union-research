# Arkansas (AR) - Corrections Pay & Benefits Profile

**Official Agency:** Arkansas Department of Corrections (ADC)  
**Union Status:** `Non-Union (Bargaining Prohibited)`  
**Union Representation:** None  
**Right-to-Work State:** Yes (AR Code § 21-1-802 expressly prohibits public sector collective bargaining)  
**Verification Level:** `HIGH — Verified via ADC Pay Grids`  

---

## 1. Executive Summary
Arkansas state correctional officers operate in a strict non-union environment where public sector collective bargaining is legally prohibited. There is no guaranteed step progression; salaries are managed within broad pay grades heavily dependent on state legislative action.

---

## 2. Base Compensation & Step Progression

| Pay Tier / Metric | Amount | Description |
| :--- | :--- | :--- |
| **Top-Out Hourly** | `$29.57/hr` | Maximum of the pay grade |
| **Exact Timeline to Top** | `N/A` | No automatic step timeline |

**Step Progression System:**
- Arkansas does not use a tenure-based step plan for corrections.
- The state uses a minimum, midpoint, and maximum pay grade system.
- Advancement toward the maximum rate ($29.57/hr) depends entirely on legislative appropriations, agency-wide pay plan adjustments, and merit increases, rather than guaranteed longevity steps.
